## Aplicacion para convertir archivos DICOM o PDF a JPG

# 🔍 Buscando librerias e informacion sobre como funcionan los archivos DICOM y PDF
  Logre encontrar librerias que me ayudaron a lograr este objetivo
  - [Pydicom]() libreria para la manipulacion de archivos DICOM, ayundome a extraer su informacion la cual utilizaria para la creacion de la imagen
  - [pdf2image]() libreria que me ayudo a manipular archivos PDF e iterando sobre sus paginas para poder guardarlas en imagen
  - [Numpy]() Con numpy pude normalizar la cantidad pixeles a la escala que una imagen JPG necesita
